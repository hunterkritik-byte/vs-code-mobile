# Sponsorship & Partnerships

## Project

**VS Code Mobile** is an independent open-source mobile development environment focused on bringing serious coding and terminal workflows to Android and the web.

The project is intentionally independent of Termux and is building its own terminal/session layer.

## What sponsorship funds

Sponsor support is intended for:

- native Android terminal and PTY development;
- security isolation and sandboxing;
- Android device compatibility testing;
- build/release infrastructure;
- documentation and developer tooling;
- open-source maintenance and contributor support.
