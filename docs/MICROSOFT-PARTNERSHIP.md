# Microsoft partnership brief

## Project

**VS Code Mobile** is an independent open-source mobile development environment with an application-owned Android terminal roadmap.

## Problem

Mobile developers need a practical environment for editing, running, and managing code on Android without requiring a separate desktop workflow.

## Product direction

- mobile code editor;
- integrated native terminal;
- isolated developer workspace;
- web and Android workflows;
- security-focused runtime architecture;
- reproducible open-source development.

## Current engineering

The repository contains an application-owned native Android process terminal and is moving toward a real PTY-based implementation.

## Sponsor-supported milestones

1. Complete native PTY and terminal resize support.
2. Add robust process groups and signal handling.
3. Build an isolated developer userspace/runtime.
4. Add signed reproducible Android releases.
5. Add SBOM and software-supply-chain provenance.
6. Expand automated Android compatibility testing.
7. Commission independent security review.
8. Improve accessibility and documentation.

## What we are asking for

We are seeking technical partnership, infrastructure support, sponsorship, and/or startup-program guidance to accelerate the open-source roadmap.

This document does not claim an existing Microsoft partnership or endorsement.
