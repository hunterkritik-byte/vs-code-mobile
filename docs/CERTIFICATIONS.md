# Certifications, audits, and verification

This project does **not** currently claim an external security certification or independent audit.

That is intentional: certificates and audit badges must come from the organization that performs the assessment.

## Verification roadmap

The project intends to pursue verifiable signals appropriate to an open-source Android developer tool:

- GitHub community health and repository security practices.
- OpenSSF Scorecard results.
- Dependabot dependency monitoring.
- Reproducible Android release/build documentation.
- Automated tests and release checks.
- Independent security review when funding permits.
- Accessibility review/testing.
- Software supply-chain provenance and signed releases.

Third-party results will be published with their issuing organization, assessment date, scope, version/commit, and report link.

No project page should describe a future target as a current certification.
