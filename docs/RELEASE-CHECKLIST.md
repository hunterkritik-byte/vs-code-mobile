# Release checklist

Before publishing an Android release:

- [ ] CI passes
- [ ] Dependency/security checks pass
- [ ] Release artifact built reproducibly
- [ ] Version and changelog updated
- [ ] APK/AAB checksum recorded
- [ ] Release artifacts are signed with the project release key
- [ ] Signing keys are never committed
- [ ] SBOM generated
- [ ] Known security issues reviewed
- [ ] Supported Android versions documented
- [ ] Installation and rollback instructions tested
- [ ] Release notes identify exact commit/version
