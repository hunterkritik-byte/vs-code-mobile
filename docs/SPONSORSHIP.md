# Sponsorship & Partnership Brief

## Project

VS Code Mobile is an independent open-source mobile development environment for Android and the web. Its roadmap includes an application-owned native terminal rather than a dependency on the Termux application.

## Why support it?

Funding can accelerate:
- native PTY implementation;
- Android device testing;
- security hardening;
- isolated developer runtimes;
- build and release infrastructure;
- documentation and accessibility;
- contributor support.

## Sponsor deliverables

Potential sponsor-supported work can be defined as public engineering milestones, such as:
- native PTY and resize support;
- reproducible Android releases;
- automated security scanning;
- runtime/package infrastructure;
- documented threat model;
- compatibility testing matrix.

Sponsorship does not imply endorsement or affiliation with Microsoft, Visual Studio Code, or any other company unless separately announced.
